## LEFT COLUMN

### Box 1 — WHAT QUICK COMMERCE IS NOW `[1][2]`
*Section label: 18pt bold ALL CAPS*

Indian quick commerce (Blinkit, Zepto, Instamart) has moved from **emergency top-up** to **weekly habit** — 10–15 min delivery via dark stores. Assortment now spans **electronics, beauty, baby care, pharma, general merchandise**.

Blinkit (Eternal Ltd.) positions as **"beyond grocery"** — public filings cite cosmetics, mobiles & accessories, electronics, baby care, fresh food, bakery. `[3][4]`

*Body: 14pt · Line spacing 1.15 · Citations [n] in red 14pt*

### Box 2 — THE GROWTH REALITY `[1][5][6][7][8]`
*Section label: 18pt bold ALL CAPS*

- **53%** place 5+ orders/month; **26%** place 10+; **63%** order weekly `[1]`
- **79%** grocery/kitchen · **74%** snacks · **42%** beauty; NIQ: **31%** primary grocery · **42%** ready-to-eat `[1][7]`
- Non-grocery grew **~1.6× faster** than grocery (Redseer Jan 2026) `[5]`
- **~₹11,000 cr** monthly QC GMV (~100% YoY) — growth from **breadth**, not grocery frequency alone `[5][6]`
- Trust/execution gaps: stockouts, returns, quality, CS constrain basket widening `[8]`

*Bullets: 14pt · 6pt space after each*

## Font size cheat sheet (Google Slides / PPT)

| Element | Size | Notes |
|---------|------|--------|
| Slide title | **36 pt** | Bold |
| Subtitle | **16 pt** | Gray |
| Section headers | **18 pt** | Bold, ALL CAPS optional |
| Body / bullets | **14 pt** | Assignment minimum |
| Stat big numbers | **32 pt** | Bold |
| Stat labels | **14 pt** | Under each number |
| Footer sources | **14 pt** | Split across 2 lines |
| Callout (red box) | **14 pt** | Bold, white on red |

**Do not use** the HTML slide’s 26px sizing — that was for Figma/Canva at 1920×1080. Slides/PPT should use **14–16pt body**.

## Quick build steps (Google Slides)

1. New presentation → **Widescreen 16:9**
2. Insert → **Table** or text boxes for 2 columns
3. Paste sections above; set fonts per cheat sheet
4. Stat cards: Insert → Shape (rounded rect) × 4
5. Tension box: Shape with fill `#2D2D2D`, text white
6. Goal + SOM: Shape with fill `#FCE8EC`
7. Footer: two text boxes at bottom, 14pt
8. Select citation text → Insert → Link (URLs table above)
9. **No fellow name** on slide (assignment rule)
